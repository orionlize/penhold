# 登录 / 注册页

**任务**：让用户用最少的输入进来，并在这一屏记住产品是谁。登录页内容最少，因此最容易做得千篇一律，也最适合放品牌记忆点。

**构图（选一个，不要默认用第一个）**
- 上下分区：上部 35–45% 是品牌区（纯色块、渐变或几何构图 + 产品名 + 一句价值主张），下部是表单；表单卡片可以向上叠入品牌区 24–32。
- 左对齐大标题：不放 logo 色块，用一句超大的欢迎语（28–34，两行）贴左边距，下面直接是输入框；页面靠字号对比而不是图形撑起来。
- 底部操作区：品牌图形占据上半屏，输入与主按钮固定在拇指易及的下半屏，第三方登录收进一行图标。
- 桌面端：左右分栏（一侧品牌与卖点，一侧表单，比例约 5:4 或 1:1），不要把一张 400 宽的卡片孤零零居中在灰底上。

**容易平庸的写法**
- 居中小 logo + “欢迎回来” + 两个灰描边输入框 + 通栏主色按钮 + “其他登录方式”分隔线。这是所有产品共用的模板，至少改掉其中两处。
- 标题只写“登录”。改成对用户说的话，带上产品语境（如“继续记你的第 37 天”“回到你的店铺”）。
- 输入框、按钮、协议勾选、第三方登录等距排列，没有主次。主路径（输入 → 主按钮）要成组，次要入口明显变小变淡。

**细节**
- 密码登录 / 验证码登录用 tab 或文字切换在同一画板内完成（proto），不要复制画板。
- 画出：输入校验错误、按钮禁用（未填完整）、验证码倒计时、协议未勾选提示。
- 协议文字 12px、不抢主按钮；“忘记密码”靠近密码框而不是页面底部。
- 主按钮文案写动作结果：“登录并继续”“获取验证码”，不写“提交”。
