# 数据看板 / 后台概览

**任务**：让使用者在几秒内判断“一切正常吗，哪里需要我处理”，然后才是细看数据。

**构图（选一个）**
- 一个主指标领衔：最重要的指标用超大数字 + 趋势占据左上大区域，其余指标缩成一列紧凑的小项，而不是四张等大统计卡。
- 待办优先：顶部是“需要处理的事项”列表（异常、待审批、临期），指标与图表退到其后。
- 主图 + 侧栏：一张主图表占 2/3 宽，右侧窄栏放排行、构成或最近动态；下方是明细表。

**容易平庸的写法**
- 一行四张“图标 + 数字 + 环比”的等大卡片，下面两张等宽图表，再下面一张表格。
- 每张卡片一个彩色图标底。颜色应只用于状态（上升、下降、异常）。
- 环比全是绿色上升箭头。放入真实的涨跌混合数据，至少一项异常。

**细节**
- 数字用表格数字（等宽数字），同列右对齐，单位和数字分开字号。
- 图表用节点画出示意即可（条、线、点），坐标轴与图例从简，标出一个关键数据点。
- 筛选（时间范围、维度）放在标题行右侧，一行解决。
- 表格行高 40–48，表头弱化，首列加粗，操作列只留 1–2 个文字按钮。
- 画出空数据与加载中的状态。
