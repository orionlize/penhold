# 引导页 / 结果页 / 空状态页

**任务**：这类页面内容很少，每一屏只传达一件事并给出唯一的下一步。内容越少，构图与文案越要用心。

**构图（选一个）**
- 大图形 + 一句话：上部 50–60% 是一个大的图形构图（色块、几何形、产品界面局部），下面一句标题、一句说明、一个按钮。
- 纯文字海报：不放图形，用超大标题（移动端 34 以上，可占三行）撑满版面，关键词用强调色。
- 结果页：结果状态（成功、失败、处理中）用大图标或大号文字居中，下面是关键信息摘要（金额、单号、时间）与下一步。

**容易平庸的写法**
- 居中的灰色线框小插画 + “暂无数据”。空状态要说明为什么是空的，并给出第一步行动。
- 引导页三屏都是“插画 + 标题 + 描述 + 圆点指示”，只有文字不同。每屏的图形与配色应随内容变化。
- 成功页只有一个绿色对勾和“操作成功”。补上用户接下来最可能需要的信息与入口。

**细节**
- 每屏一个主按钮；“跳过”用文字放在右上角或按钮下方。
- 多屏引导用 proto 变量切换同一画板内的面板，指示点跟随变化。
- 文案具体：写出用户得到了什么（“已预约周六 14:00 的课程”），而不是系统做了什么。
