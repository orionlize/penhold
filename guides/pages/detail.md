# 详情页（商品、文章、订单、个人资料详情）

**任务**：把一个对象讲清楚，并让主行动始终够得着。

**构图（选一个）**
- 沉浸头图：顶部大图或大色块占满宽度（移动端约 40–50% 屏高），标题与关键信息压在其下缘或叠入，导航栏浮在图上。
- 关键信息置顶：没有好图时，用超大标题 + 一行关键数据（价格、状态、时间）开场，其余内容按重要性依次展开。
- 桌面双栏：左侧主内容滚动，右侧窄栏固定放摘要与主行动（购买、预约、审批）。

**容易平庸的写法**
- 把每个字段组都包进一张相同的白色圆角卡片，页面变成一摞卡片。优先用标题 + 留白 + 分隔线分节。
- “标签：值”两列表格从头排到尾，没有任何一项被强调。
- 底部并排三个等宽按钮。只保留一个主按钮，次要操作改成图标或文字。

**细节**
- 主行动固定在底部（移动端）或侧栏（桌面），按钮文案写结果（“加入购物车 · ¥129”）。
- 价格、评分、状态这类关键值用更大的字号或强调色，全页只强调一两处。
- 长文本默认收起到 3–4 行并给出“展开”。
- 画出相关状态：售罄 / 已结束 / 不可操作时主按钮的禁用与说明。
