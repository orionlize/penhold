# 落地页 / 官网首页

**任务**：让访客在首屏明白“这是什么、对我有什么用”，并愿意点主按钮。每个区块只说一件事。

**首屏构图（选一个）**
- 文字主导：超大标题（桌面 56–72，两行内）左对齐，占据左侧 60%，右侧是产品界面的局部特写，而不是整张截图缩小。
- 产品即主视觉：标题短而居中，下面一张大的产品界面图从首屏底部“探出”一半，引导向下滚动。
- 一句话 + 一个输入：首屏只有一句主张和一个可以直接开始的输入框或按钮，其余全部留白。

**区块节奏**
- 首屏之后的区块要有疏密与版式变化：通栏大图、左图右文、三列要点、一句引言交替出现，不要连续三个“三列图标 + 标题 + 描述”。
- 常用顺序：价值主张 → 产品如何工作（真实界面）→ 关键能力 → 证明（数据、客户、评价）→ 价格或行动号召。按内容需要删减。

**容易平庸的写法**
- 居中标题 + 渐变高亮的关键词 + 两个并排按钮 + 下方一张带阴影的截图。
- “功能特性”做成六张图标卡片的网格，每张一个图标一句话。挑三个最重要的，用真实界面局部说明。
- 标题写“重新定义××”“一站式××平台”。改成具体的结果或数字。

**细节**
- 整页只有一个主行动，重复出现时文案保持一致。
- 导航 4–6 项，主按钮在最右。
- 页脚从简：分组链接 + 版权，不要再放一遍大标题。
