# 个人中心 / 设置页

**任务**：个人中心回答“我的状态如何、我的东西在哪”；设置页让用户快速找到并改掉一项配置。

**构图（选一个）**
- 身份 + 状态开场：顶部不只是头像和昵称，而是把用户最关心的一项状态做大（余额、会员进度、本周数据），入口列表在其后。
- 分组设置列表：按主题分 3–5 组，组标题用小号次要色；每行左侧文字、右侧当前值或开关。
- 桌面端：左侧设置分类导航，右侧为当前分类的表单，一次只显示一类。

**容易平庸的写法**
- 渐变头部 + 圆头像 + 三个数字统计 + 一长串“图标 + 文字 + 箭头”的入口。
- 每个入口配一个不同颜色的图标底。改为单色图标或不用图标。
- 所有设置项平铺成一个超长列表，没有分组。

**细节**
- 开关、单选这类即时生效的设置直接放在行内，不要再跳一页。
- 行右侧显示当前值（“简体中文”“已开启”），减少点进去才知道的情况。
- 危险操作（退出登录、注销账号）与普通项分开放在最后，用危险色文字而不是大红按钮。
- 画出开关的开 / 关两态（proto.toggle）。
