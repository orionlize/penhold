# 首页（App 首页 / 信息流 / 发现页）

**任务**：一眼回答“我现在最该看什么、做什么”。首页不是功能目录。

**构图（选一个）**
- 一个主角 + 其余从简：首屏上部给最重要的一件事（今日数据、进行中的任务、主推内容）一个大区域，下面的内容降级为紧凑列表。
- 不等大的拼贴：用 2–3 种尺寸的内容块组成网格（一个大块配两个小块），大小对应重要性，而不是 2×N 的等大宫格。
- 时间线 / 信息流：单列内容连续滚动，顶部只留搜索或筛选；靠内容本身的图文节奏变化，而不是每条都套同一张卡片。

**容易平庸的写法**
- “问候语 + 搜索框 + 轮播 Banner + 八宫格图标 + 横滑卡片 + 列表”的全家桶。每加一个模块先问：去掉它用户会不会找不到要做的事。
- 所有模块同样的卡片、同样的圆角与间距，没有视觉重音。
- 金刚区图标各用一个彩色圆底。改用单色图标，或干脆用文字入口。

**细节**
- 首屏（移动端约 700 高）内必须出现页面的主角与主行动。
- 区块标题左对齐，右侧“查看全部”用文字，不要每个都配箭头图标。
- 底部 tab 3–5 项，当前项除了颜色还要有形状或字重的区别。
- 用真实量级的内容：真实的标题长度、价格、时间，包含一条偏长和一条偏短的样例。
